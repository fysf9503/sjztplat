3. 技术约束

- 后端使用 Java 21、Spring Boot 3.2、Spring Cloud、Spring Data JPA 和 Druid。
- 前端使用 Vue 3、Vite、Element Plus、ECharts。
- Gateway 使用 Spring Cloud LoadBalancer 解析 lb:// 服务路由。
- Nacos 中服务名必须与网关路由和 spring.application.name 保持一致。
- Doris 使用单机时，建表应使用 UNIQUE KEY 或 DUPLICATE KEY 模型，并设置 replication_num=1。
- 任务调度只由 DolphinScheduler 执行，平台不再以 XXL-Job 作为调度实现。
- 资产、术语、标签和血缘以 OpenMetadata 为权威来源；平台仅保存关联标识和业务配置。

4. 配置原则

4.1 控制面与数据面

控制面保存数据源、任务、依赖、质量规则、运行记录和权限等业务元数据。数据面保存接入后的业务数据、质量结果与查询结果。

- 控制面应使用适合事务写入的关系数据库。
- Doris 用于分析数据、宽表、统计结果和大批量质量明细。
- 数据源密码须加密存储；接口返回时必须脱敏。

4.2 数据源

数据源配置至少包含：名称、类型、JDBC URL、用户名、密码、默认库、连接参数、负责人和状态。

连接测试必须在保存前执行，测试结果需要记录测试时间、状态与错误信息。创建接入任务时只能选择已通过测试且状态启用的数据源。

4.3 任务依赖

每个任务可声明多个前置任务。平台保存依赖图后同步为 DolphinScheduler 工作流；循环依赖必须在保存时阻止。

5. 启动顺序

1) 启动基础设施

cd docker/compose
docker compose -f docker-compose.core.yml up -d
docker compose -f docker-compose.scheduler.yml up -d
docker compose -f docker-compose.metadata.yml up -d

2) 初始化 Doris

mysql -h 192.168.81.104 -P 9030 -u root -proot < sql/doris_ddl.sql

3) 启动后端服务

1. data-auth
2. system-service
3. data-integration-service
4. data-quality-service
5. data-governance-service
6. data-lineage-service
7. data-realtime-service
8. data-gateway

启动后在 Nacos 控制台确认所有实例为 healthy=true。

4) 启动前端

cd data-ui
npm install
npm run dev

默认访问地址为 http://localhost:9528。

6. 运行排查

- 401：前端未携带 JWT，或令牌已失效。
- 503：Gateway 未发现目标服务；检查 Nacos 服务名、健康状态和 LoadBalancer 依赖。
- 500：请求已进入后端；查看对应服务 logs/<service-name>.log。
- 请求参数异常：Controller 的 @RequestParam 和 @PathVariable 必须显式声明 value，例如 @RequestParam(value = "pageNum")。
- 访问数据源失败：检查 JDBC URL、网络端口、账号密码和驱动。
